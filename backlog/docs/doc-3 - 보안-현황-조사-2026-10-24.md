# 보안 현황 조사 (2026-10-24, 플랫폼 전환 계획 근거)

OWASP Top 10 2021 / ASVS L2 기준. 읽기 전용 조사 결과다. 인가·입력 검증·세션·레이트리밋은 잘 되어 있다. 가장 큰 구멍은 두 가지다.
- 응답 보안 헤더가 사실상 없다.
- CI에 의존성·시크릿 스캔이 없다.

## 이미 있는 방어
| 범주 | 근거 |
|---|---|
| CSRF | `SecurityConfig` csrf.spa(), XSRF-TOKEN 쿠키(SameSite=Lax). 면제는 Bearer·refresh·token=jwt 로그인 경로뿐(근거 주석 있음) |
| 세션 | HttpOnly·SameSite=Lax·Secure(env), 절대 만료 14일, 로그인 시 changeSessionId, 운영 Secure 강제(ProductionSafetyCheck) |
| 인증 | bcrypt, 비밀번호 8자 이상·72바이트 이하. 레이트리밋(계정+IP, IP, 가입, step-up, OTP). JWT HS256 고정에 iss·exp 검증. 운영 시크릿 품질 검사 |
| 인가·IDOR | deny-by-default, /admin/** ADMIN만. OwnershipChecker, 글·댓글·첨부 소유권 검사 |
| Mass assignment | record DTO, FAIL_ON_UNKNOWN_PROPERTIES, 제어 문자 거부 |
| Injection | JPQL 파라미터 바인딩, native는 상수 문자열, LIKE 이스케이프 |
| XSS | 본문·댓글을 React 텍스트로 렌더, dangerouslySetInnerHTML·markdown·eval·postMessage 없음, rel=noopener |
| Open redirect | safeNext, OAuth는 PUBLIC_BASE_URL 기준 |
| 업로드 | png/jpeg/webp/gif만(SVG 없음), 5MB, 키는 UUID, presign에 타입·길이·덮어쓰기 금지 서명, 확정 시 HEAD 재확인 |
| 오류 노출 | 5xx는 일반 메시지만, DB detail 로그 끔 |
| 요청 제한 | 본문 64KB, multipart 끔, 페이지 상한, DB·외부 호출 타임아웃 |
| Actuator | health만 노출, 상세는 ADMIN |
| 인프라 | 비루트 컨테이너, IMDSv2, SSH 없음, CloudFront prefix list, S3 OAC·퍼블릭 차단·암호화 |
| 감사·PII | 관리자 감사 로그, 전화번호 마스킹 |

## 갭 → 담당 draft
| 갭 | 심각도 | 담당 |
|---|---|---|
| HTML 응답에 CSP·HSTS·frame-ancestors·nosniff·Referrer-Policy·Permissions-Policy·COOP/CORP 없음(클릭재킹 가능) | H | 프론트 하드닝(Next), AWS 단계(현재 정적 배포 응답 헤더 정책) |
| CI에 npm audit·dependency-check·Trivy·CodeQL·gitleaks·SBOM·Dependabot 없음, 액션 태그 고정 | H | 공급망·CI 보안 |
| /api에 HSTS가 안 나감(CloudFront→EC2 HTTP, forward-headers 없음) | M | 백엔드 하드닝 |
| /uploads에 nosniff·CSP·Content-Disposition 없음, 매직바이트 검사 없음 | M | 백엔드 하드닝 |
| CORS 설정 없음(새 프로토콜·오리진 대비) | M | 백엔드 하드닝 |
| 계정+IP 키라 분산 credential stuffing에 약함, 유출 비밀번호 검사 없음 | M | 백엔드 하드닝 |
| 보안 이벤트 로그(로그인 성공·실패 등) 없음 | M | 백엔드 하드닝 |
| JWT HS256 대칭키, aud 없음 | M(향후) | 백엔드 하드닝(aud), AWS 단계(비대칭키 검토) |
| WAF 없음 | M | AWS 단계 |
| 세션 유휴 타임아웃·세션 목록 없음 | L-M | 백엔드 하드닝 |
| OAuth PKCE 명시 안 함 | L | 백엔드 하드닝 |
| JSON 깊이 제한 명시 안 함, Tomcat 타임아웃 미설정 | L | 백엔드 하드닝 |
| Docker 베이스 digest 미고정, rootfs 쓰기 가능 | L | 공급망·CI 보안 |
| 개발 기본 시크릿이 커밋되어 있어 스캐너 오탐 | L | 공급망·CI 보안(gitleaks allowlist) |

## Next 서버 전환 시 새로 생기는 표면
- 서버 fetch, Server Actions, image optimizer가 생기므로 SSRF 표면이 늘어난다.
- RSC 인라인 스크립트가 있어서 CSP에 nonce가 필요하다.
- 쿠키 전달과 클라이언트 IP 헤더 체인을 다시 설계해야 한다(IP 위조 위험).
- 새 프로토콜(WS/STOMP, SSE, gRPC, GraphQL, Kafka, Webhook, MQTT, JSON-RPC)에는 64KB 필터, CSRF, 레이트리밋, @PreAuthorize가 자동으로 걸리지 않는다. 프로토콜마다 인증, 메시지 단위 인가, 크기·연결·속도 한도, Origin 검사를 명시해야 한다.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
독립 리뷰(2026-10-24) 반영 결정(유저): CF Function 페이지 목록(PAGES) 방식 유지 — README에 'terraform apply(PAGES) → deploy-frontend' 순서, 롤백(deploy-frontend)은 함수를 되돌리지 않는다는 주의, viewer-response 연결로 기본 동작 함수 호출이 두 배(100만 건당 $0.10) 추가. 알림 역할: 정지 경고 중 세션 끊기 실패(session_revoke_failed)만 alert, 재조회 실패 안내·제한 세션 상단 배너는 status. 확장자가 있는 없는 경로(/robots.txt 등)의 S3 XML 404는 범위 밖(README 한계 유지).

오류 경계·404·접근성을 정리했다.
- AC#1 FE-34: app/error.tsx·global-error.tsx(자체 html lang=ko)·not-found.tsx를 한국어로, '다시 시도'는 Next 16 retry. 원문 오류는 콘솔만. out/404.html 생성 확인.

B1: /api·/uploads 동작에는 함수가 없고 함수 안에서도 통과(tftest·cf_function_test로 고정). PAGES는 app의 page.tsx 목록과 테스트로 동기화. 배포 순서 terraform apply → deploy-frontend, 롤백 주의, 함수 호출 두 배 비용은 README에(유저 결정: 목록 방식 유지).
- AC#3 FE-36: Alert role을 variant로 — 오류(destructive)만 alert, 안내는 status. 정지 경고는 session_revoke_failed면 alert(유저 결정). 편집기·댓글 필드 오류에 aria-describedby·aria-invalid.
